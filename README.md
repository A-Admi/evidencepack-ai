# EvidencePack AI

**Local-first security evidence packaging for bug bounty researchers, pentesters, security consultants, and internal security teams.**

EvidencePack AI helps turn messy research evidence—logs, notes, scripts, requests, responses, screenshots, and other artifacts—into a structured package that is easier to review and prepare for responsible submission.

## Privacy-first

EvidencePack AI is designed for local processing. It does not require cloud AI or a cloud model. Pro can optionally use a locally running Ollama instance.

Always review generated reports, redactions, and AI interpretations before submission.

## Human review stays in the loop

EvidencePack AI organizes evidence and drafts reports. It does **not** scan remote systems, exploit targets, steal credentials, or automatically submit vulnerability reports.

Researchers remain responsible for authorization, scope, factual accuracy, impact claims, and final submissions.
