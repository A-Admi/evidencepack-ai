## Product Hunt

### Name

EvidencePack AI

### Tagline

Local-first security evidence packaging for researchers and pentesters

### Short description

Turn logs, notes, scripts, requests, screenshots, and other security research artifacts into a structured evidence package with SHA-256 manifests, secret review, provenance-aware report material, and optional local Ollama assistance.

### Maker comment

I built EvidencePack AI because the final stage of security research often turns into a manual evidence-cleanup job: logs in one folder, screenshots somewhere else, notes that do not map cleanly to claims, and last-minute checks for secrets before a report is submitted.

The Free edition handles evidence inventory, SHA-256 manifests, metadata, basic secret detection, and report templates.

The Pro edition adds local Ollama-assisted drafting, evidence-to-claim mapping, consistency review, reproduction-step drafting, redaction suggestions, multiple report structures, and submission-package generation.

The design goal is simple: keep evidence local, keep the researcher in control, and make the final package easier to audit before disclosure.

I would especially value feedback from bug bounty researchers, pentesters, security consultants, and internal security teams on what is still missing from the workflow.
