# First 20 Users — Tracking Plan

Goal: get 20 genuine Free users before making major new product features.

## Funnel

Visitor
→ landing page
→ Free product page
→ download
→ first successful run
→ feedback
→ optional Pro upgrade

## Track weekly

- Landing-page visits, if a privacy-respecting count becomes available without paid tooling
- Free downloads
- Pro purchases
- Support messages
- Confirmed first runs
- Feedback responses
- Source/channel when known

## Qualitative questions

Ask early users:

1. What were you trying to package?
2. What part of the workflow was most useful?
3. Where did you get stuck?
4. What did you expect the tool to do that it did not do?
5. What would make Pro worth paying for?
6. Would you use this again for your next report or engagement?

## Decision gates

### After 20 Free downloads

If almost nobody runs the application:
- fix onboarding/download trust/friction before adding features.

If people run it but do not finish a package:
- fix workflow/UI friction.

If people finish packages but do not want Pro:
- test whether Pro features solve a strong enough problem.

If Pro converts:
- interview buyers and prioritize the reason they paid.

Do not infer product-market fit from page views alone.
